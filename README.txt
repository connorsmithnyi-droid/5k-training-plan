STRIDE 5K — YOUR PERSONAL TRAINING APP

FILES
index.html = application; manifest.webmanifest and sw.js = home-screen/offline support; icons = app icons.

TRY IT:
Open index.html in a browser (preferably on a computer). Tracking stores data locally in that browser.

INSTALL ON AN IPHONE (OR ANDROID):
Upload ALL files in this directory together to any HTTPS static web host (GitHub Pages, Netlify Drop, Cloudflare Pages etc.). Visit the hosted website on your phone.
On iPhone in Safari: Share > Add to Home Screen > Add. On Android in Chrome: menu > Add to Home Screen / Install app.
Once installed and first loaded, the app can work offline. You do not need an App Store account.

IMPORTANT:
The HTML file alone can be opened in some mobile browsers, but is NOT a native iOS/Android package and may not be installable to the home screen offline without HTTPS hosting. Data is per browser/device. Use Export backup regularly.
